# Separate analysis outputs (`Results`)

This directory is preserved for the separate scripts in `../Scripts/Other_analyses/`, whose original Stata output configuration references `Results`.

- `intergen_wealth_transition_*` and `transition_matrix_*`: transition matrices, samples, and plots from the 2026-05-19 and weighted 2026-05-20 intergenerational transition scripts.
- `Figures/DiD_*`: figures retained from alternative/earlier inheritance-DiD analyses (not the current child trajectory model).

The old parent/child wealth-trajectory figures and workbooks that previously shared this `Results` folder were moved to `../Archive/Outputs/Original_Results_legacy/`. Archived alternative analysis scripts still have original absolute paths and might need output-directory adjustments before re-running.
