# Historical shared-with-Elisa folder snapshot

These files were described by the project author as copies once uploaded to Elisa's Git repository/shared drive. This archive preserves the original contents and relative folder structure of the former `From Elisa/` folder. It does **not** assert that Elisa authored these files or that every file is the most recent estimate.

- `Results_new/Coefficients/`: two final May 26 LOWESS fan workbooks that are byte-identical to the main working copies, alongside older coefficient alternatives.
- `Results_new/Figures/`: historical PDFs, some of which differ at the byte level from similarly named figures in `Results_new/Figures/`. Difference alone does not prove statistical revisions.
- `Wealth_trajectories/`: downstream/shared trajectories, including undated extrapolation workbooks that are not exported **under those names** by the current Stata scripts.
- `Wealth_trajectories/Old/`: explicitly historical alternatives. Files with a trailing ` 2` are exact byte-duplicates of the files without that suffix; both have been kept in this preserved snapshot.

Use `../../Results_new/` for canonical output files rather than this snapshot. No files in this snapshot were individually deleted or altered.
